1. Diseño de la Tabla de Símbolos

La Tabla de Símbolos se ha implementado como una estructura de diccionario (Hash Map) optimizada para búsquedas rápidas (O(1)). Su función principal es registrar cada identificador (comando) encontrado y rastrear su contexto de uso.

Estructura de Datos:
{ "LEXEMA": { "kind": "TIPO", "occurrences": [L1, L2, ...] } }

Lógica de Inserción:

def insert(self, name, kind, line):
    if name not in self.symbols:
        self.symbols[name] = {"kind": kind, "occurrences": [line]}
    else:
        self.symbols[name]["occurrences"].append(line)

2. Diseño de la Pila de Errores

Se utiliza una clase ErrorPile que actúa como un acumulador de objetos ErrorEntry. Esta estructura permite que el traductor no se detenga ante el primer fallo, sino que recolecte todos los errores encontrados para presentarlos al usuario al final del proceso de análisis.

Atributos de un Error:
[Código de Error] | [Mensaje Descriptivo] | [Línea] | [Columna]

3. Autómatas y sus Grafos

3.1 Autómata Finito (Lexer)

Maneja el análisis léxico mediante una matriz de transiciones de 10 columnas (clases de caracteres) por 10 estados.

E/CLTRDIGQUOPSCSLHSPCNL
Q0Q1ErrQ2Q7Q4Q0Q0
Q1Q1Q1AccAccAccAccAcc
Q2Q2Q2Q3Q2Q2Q2Err

(Simplificación: Q1=Comando, Q2=Cadenas, Q4=Comentarios, Q7=PuntoComa)

3.2 Autómata de Pila (Parser)

El PDA utiliza una pila para validar el anidamiento. Por ejemplo, al encontrar LISTA, apila ul. Al encontrar ;, desapila el tope. Si el tope no coincide con la estructura esperada, se dispara un error semántico.

6. Categorización de los Errores

L001 (Léxico)
Caracteres no reconocidos por el alfabeto o cadenas mal cerradas.
P001 (Sintáctico)
Secuencia de tokens que no sigue la gramática (ej. dos puntos y coma seguidos).
S001 (Semántico)
Violación de reglas de contexto (ej. ELEMENTO fuera de una LISTA).
C001 (Comando)
Uso de una palabra reservada que no existe en el diccionario del lenguaje.
